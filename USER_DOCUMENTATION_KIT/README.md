## 🖨️ How to Export the Beautiful PDF Guide (3 Clicks)

1. Double-click or open [MANUAL_GUIDE.html](file:///c:/Users/skand/OneDrive/Desktop/Personal%20Clients/Pradeep%20Nadig%20-%20Portfolio%20+%20E-Commerce/Apps/V1%20-%20Antigravity/USER_DOCUMENTATION_KIT/MANUAL_GUIDE.html) in **Google Chrome** or **Microsoft Edge**.
2. Click the orange **"Print / Save as PDF"** button at the top (or press `Ctrl + P`).
3. In the print dialog:
   - **Destination:** Choose *Save as PDF*.
   - **Pages:** *All*.
   - **Layout:** *Portrait*.
   - **More Settings -> Background Graphics:** Check the box (ensures background colors and badges look vibrant).
   - Click **Save**.

You now have a clean, publication-grade PDF manual with embedded color screenshots, numbered callouts, and clean page breaks!
