# Tutorial 3: Ritual Services & Astrology Consultations CMS

## Overview & Objective
Learn how to create, edit, publish, and curate ritual services (Homas, Pujas, Sevas) and Vedic Astrology Consultation packages using the Offerings CMS module.

---

## Prerequisites
- Administrator portal access (`/admin/offerings`).
- High-resolution ritual image URL or Media Library asset ID.
- Service summary, full description, and SEO slug.

---

## Spoken Narration Script (NotebookLM Narration)

"Welcome to the Ritual Services and Astrology Consultations CMS tutorial. In this video, we will cover how to manage your service catalog on the website.

Navigate to Offerings from the admin menu. The Offerings page displays all available rituals and astrology consultations, showing their offering type, title, custom URL slug, and current publication status.

To add a new ritual or consultation, click the Add New Offering button at the top of the page. In the modal interface, select the Offering Type: choose Service for rituals such as Ganapathi Homa or Satyanarayana Puja, or Consultation for Vedic Astrology and Naming Guidance.

Next, enter the Title and review the automatically formatted URL slug. Click the Media Library button next to the Cover Image field to select a picture from your media repository.

Provide a concise Short Description for card previews, followed by a detailed Full Description explaining the spiritual significance, ritual process, and requirements.

Set the Status to Published to make it immediately visible on the website, or set it to Draft if you are still preparing the content. Finally, click Save Offering to store your changes."

## Common Errors & Troubleshooting

| Problem | Cause | Recommended Action |
| :--- | :--- | :--- |
| **Offering missing on public site** | Status set to `Draft` or `Archived`. | Open offering editor and update status to `Published`. |
| **Image broken on public page** | Invalid cover image URL or broken external link. | Select a valid asset from the Media Library using the picker button. |
